## 自动化测试重点（后续代码阶段）

优先覆盖会损坏记录或误导学习结果的规则：评分和允许的答案归一化、练习追加与重复恢复去重、非法内容包事务回滚、修订不可变、正式提交原子性/幂等性、重玩禁止写正式事实、双入口共享 ID 和版本、证据来源与技能升级约束。持久化测试需实际关闭连接再读取。

核心集成测试使用临时数据库与原创 DEMO 数据；测试不得读写真实学习档案。UI 验收重点为断网启动、导航、复制任务卡、导入/恢复预览和错误提示。原生 SQLite 兼容性与本机打包需在实际 Electron 环境验证，不能仅靠 Node 单测。

功能尚未编写时不创建镜像实现的测试。S0 只检查文档完整性、内部链接、必需概念和 Git 差异，不将这些检查称为应用测试。
