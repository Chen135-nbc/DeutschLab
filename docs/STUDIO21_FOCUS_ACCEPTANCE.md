# Studio21 A1 第一单元与 Focus Mode 验收

日期：2026-10-15 · 版本：0.3.0。

## 实现范围

- 主线目录新增 `Lektion 1 · Kaffee oder Tee?`，教材范围第 16–31 页。四个教学小节对应 16–23 页；24–30 页作为教材练习范围，31 页对应单元自测与总结，不拆出额外教学小节。
- 内容包包括 18 张结构化知识卡、四节共 18 道原创练习题、9 道单元综合检测题。卡片有稳定 ID、分类、学习层次、解释、原创例句、关联卡片和页码范围；练习题有稳定 ID、知识点、参考答案、解析。内容依据用户本次提供的概要，没有逐页核对教材照片，也没有复制教材原题/对话/听力。
- 四种题型使用同一判分模块：单选、匹配、填空、排序。有限填空按列出的可接受答案判分，忽略前后空白、连续空白和大小写，保留德语变音与 ß 的拼写差别。
- Focus Mode 使用独立全窗口路由与同一容器，隐藏原侧边栏。知识卡一次显示一张，可前后切换、按 Esc 返回；练习一次显示一题，可看提示、临时查看关联卡片并返回当前题目。退出未提交答案时提示，已提交答案立即持久保存，可中断并续学。
- 第一单元课程页提供知识卡检索、教材/录播课手动状态、知识卡浏览与练习状态、错误知识点回看。综合检测显示答题数、正确数、错误知识点和重练入口。学习统计新增答题记录。客观题结果不自动点亮能力树。
- 第一单元通过现有 `A1-Bxx-Uxx` 专题 ID 关联 A1 自学框架，只表示教材涉及相关主题。

## 内容与数据组织

`content/studio21/a1/lektion1.json` 是独立内容包，`src/domain/studio21.ts` 校验 ID/引用/答案并提供统一判分。知识卡和题目不写在 React 页面内。未来增加第二单元可沿用相同内容结构、判分函数、Focus 页面和数据库表；内容校验允许第二个内容包直接引用第一单元既有知识卡 ID，不复制卡片正文。仍需登记第二个内容包和课程路由。

SQLite schema v3 新增不可变内容修订、手动学习状态、卡片浏览、上次位置、练习会话和逐次作答表。旧 schema v1/v2 事务升级；原设置、浏览历史、A1 框架及能力树表保留。每次答题记录题目快照、内容修订及判分规则版本。内容版本改变不会删除旧答案；历史列表显示当时题干，数据库保留完整题目快照。

## 已知限制与后续建议

课程知识点是依据本次文字概要原创整理，尚未逐页与教材照片核对。当前只覆盖第一单元；其他 11 个正式单元和 Station 未接入。没有教材原版音频、听力判分、自由口语/长篇写作、AI 评分或云同步。未提交的草稿会在退出前提示，但不会写为正式答题记录。综合检测的正确率仅表示基础知识表现，不能证明实际交际能力。

下一步可在获得原始教材材料后核对页码与知识精度；随后以同一内容包格式接入第二单元，验证跨单元知识卡引用与复习。若历史记录继续增大，再为统计页引入分页读取；目前本地数据库保存全部提交，界面显示最近 30 次。
