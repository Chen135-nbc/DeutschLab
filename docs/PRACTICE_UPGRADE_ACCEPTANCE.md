涵盖自我介绍、来源、du/Sie、点饮料、规则动词与 sein、句型、偏好和简单搭配、数字 1–1000、电话、价格、账单及结账。新增题以完整句子和短情境为主。数字部分有四道通过受控脚本生成并核对拼写的变式；正式题目写入版本化 JSON，不在答题时由 AI 生成。

基础巩固优先 Level 1–2，综合提高优先 Level 2–3，错题强化优先历史错误知识点的不同题目。每节每次抽取至多 12 题。随机种子与题单在会话创建时固定，重启后按原顺序继续。单元检测为固定 18 题。结果显示总分和三个难度分项；知识卡查看、答题快照与历史记录沿用原存储规则，能力树仍不自动点亮。

SQLite schema v4 新增 `practice_plans`，保存会话题目 ID 顺序。v3 升级时，从当时的课程内容修订补齐已有会话题单；旧答题和课程修订保留。课程包版本升至 1.1.0。A1 自学框架和能力树源 JSON 未修改。

验证：`npm test` 构建与 19/19 数据测试通过，覆盖所有 83 道题的正误答案、题目引用与唯一性、金额结果、数字拼写、抽题层级、错题优先、题单与历史重启持久化、旧 v3 会话迁移。源码 Electron 和最终 `.app` 均通过 17/17 桌面测试，覆盖练习入口、18 题综合检测、Focus Mode、重启续学、页面导航和窗口适配。

限制：题目依据用户提供的课程概要编写，尚未逐页对照教材原件。Level 3 仍是 A1 范围内的短情境客观题，不能证明实际口语能力。数字变式目前是经脚本预生成的有限题组，不是无限随机题库。
