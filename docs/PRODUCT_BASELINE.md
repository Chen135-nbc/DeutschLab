## 目标与资料优先级

DeutschLab 是个人长期使用、电脑本地运行优先的智慧德语学习工作台。Studio21 为真实教学主线，自学框架组织专题、交际能力和副本主题。内容和功能随实际进度从 A1 生长至 B2。

优先级：用户最新明确安排 → 最新确认的产品设计 → 本次启动文档 → 未确认建议。仓库为空，未发现《产品设计初版报告 v0.2（2026-10-10）》、阶段报告、课程目录或自学框架，因此当前无法比较新旧差异。资料到齐后先记录冲突，不自动覆盖基线。

首要成果是一个真实 A1 单元的闭环与第二单元的数据复用验证。启动轮（2026-10-13）交付方案和文档；当前桌面外壳阶段的实现边界见文末记录。

## 模块及最小边界

| 模块 | 必须保留的行为 | v0.1 范围 |
| --- | --- | --- |
| Studio21 主线 | 真实教材顺序；概览、核心词汇四选一、语法匹配/选择/填空、检测与进度 | 一个真实单元，随后增加第二单元；既有背词工具保留关联/跳转位置 |
| 自学专题拓展 | 按已有框架映射当前所学；拓展词汇、语法、场景讲解、基础造句 | 材料缺失时只有 DEMO 专题；造句检查确定性规则 |
| 趣味副本 | 以专题为骨架；课内及主页双入口；搜索、重玩、版本和历史共享 | 一个短副本；难度可用内容版本逐步增补 |
| 平行德国人生 | 副本类型；地点、NPC、事件、语言任务分开；允许一次性相遇 | 一个面包房或教室 DEMO 场景，有限可汇合分支 |
| 一句话的100种可能 | 同一交际意图按等级、语境、语气、语体保存有价值版本 | 最小表达集合与关联入口；不要求凑齐100条，不与造句合并 |
| 真实世界德语采集 | 手动保存文本、主题、推荐等级和出处 | 最小手动保存/列表；后续再增加阅读、听力、写作任务 |
| 知识星系 | 词汇、语法、表达节点及跨分支关系 | 列表、关联与跳转 |
| 能力树 | 已有 A1/A2 框架和真实交际任务为主干；主线与专题多对多 | 接触/学习状态与独立运用/复测证据分别展示 |
| 统一学习档案 | 稳定 ID；内容与用户记录分离；每次练习新增历史；反馈来源可区分 | 本地保存、历史检索、备份与恢复 |

## 副本的四个独立维度

| 维度 | 可选值 | 规则 |
| --- | --- | --- |
| 入口 | 拓展课内 / 主页副本库 | 只表示从哪里来，不能生成两个副本对象 |
| 玩法 | 定向训练 / 自由探索 | 课内默认定向；独立入口可选两者；自由探索仍是有限预设事件 |
| 备注 | 显示 / 隐藏 | 只控制目标、提示和标签展示，不改变判分或剧情 |
| 剧情状态 | 正式探索 / 练习重玩 | 正式探索在预览并确认后更新世界事实与玩家已知信息；重玩只保存学习表现和会话日志 |

入口使用同一 `quest_id`；相同发布版本下引用同一内容，历史可跨入口查询。进行中的会话固定版本，新会话可显式采用更新版。

用户可以先开口说德语，再点击剧情意图。按钮只推动剧情；无语音识别时不会产生口语准确度或发音评分。没有提交语言答案时，语言评分为空。

## 学习反馈和 ChatGPT 协作

基础造句训练词形、变位、语序、冠词和格；表达深化训练表达版本与使用场合，两者使用不同题型与证据。预设答案或有限规则检查必须标明范围；未命中答案不能直接推断为语法错误。

场景保存外部教练任务卡，包含等级、目标、人物背景、已知 NPC 台词、待评知识点及反馈格式。电脑复制，用户手动发送手机 ChatGPT；用户再手动录入摘要。GPT 反馈不决定剧情，不自动升级技能，不在缺少真实音频时评价发音。反馈展示来源、输入方式和可信度说明，不把来源标签自动解释为可靠评分。

## 已有约束、假设与待定项

启动文档明确：个人用途、本地离线优先、不依赖 GPT API、不部署云服务器、不开发手机端、不复刻完整背词 APP、不预建全部等级或完整社会模拟。iCloud、自动聊天同步、自由语音理解、复杂星系动画均不属于 v0.1 完成条件。

本轮假设：先支持当前 Mac；界面中文为主、德语内容保留原文；一个本地用户档案；没有真实材料时用原创 DEMO。以上为非阻塞假设，可随用户安排调整。

桌面外壳已采用现有 Electron/React/TypeScript/SQLite 建议。仍待确认：真实单元材料、准确教材版本/章节标识；A2 框架（A1 JSON 已在后续任务提供）；背词工具名称与跳转方式；“独立运用/经复测”的任务标准；正式剧情确认粒度；分发和应用签名需求。材料与框架缺口阻塞真实课程验收，但不阻塞桌面壳搭建。
