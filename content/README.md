# 内容材料准备

当前有用户提供的 [A1 自学框架](frameworks/a1/a1_extension_framework.json)及[能力树配置](frameworks/a1/a1_ability_tree.json)，共 8 板块、68 单元、207 内容项、16 完成目标。原样复制，不改标题、顺序、文本或 ID，没有具体 Studio21 映射。

旧 [DEMO 目录](demo/catalog.json)继续用于主线/副本和独立演示专题；旧能力占位不再显示在 A1 能力树。没有真实讲义、题库或通用文件导入器。

## 真实材料

接入时记录教材版本、真实章节标识、用户提供的讲义/笔记、出处、个人学习用途说明，以及可用的 A1/A2 框架。只处理用户合法提供并确认可用于个人学习的材料，不自动抓取或大量复制教材。

原始私人材料建议放 `content/private/`（Git 忽略）；可分发的原创内容和许可清楚的内容包再纳入版本管理。导入器只读明确选择的包，不扫描 Downloads 或其他私人目录。

## DEMO

无讲义时可少量创建原创 A1 DEMO，例如问候或面包房购买任务。包、单元、页面和导出清单明确标注 DEMO，来源标为原创演示；不命名为 Studio21 某真实章节，也不伪造自学框架。

已采用 `demo.course.first-contact` 和 `demo.course.simple-order`；两者及两个专题都引用唯一的 `demo.quest.bakery`，并复用问候知识节点。副本只包含描述、NPC 台词和目标的界面预览；没有生成题目或剧情引擎。首页、目录、详情都明确显示 DEMO。

## 拟议内容包

包清单包含 pack_id、pack_version、schema_version、来源、DEMO 标志和资源清单；实体包含稳定 ID、revision_id 与引用。JSON 用于结构化数据，Markdown 用于讲解。更新新增不可变版本；导入不接受用户记录或可执行脚本；用户恢复走单独流程。

详见[概念模型](../docs/DATA_MODEL.md)。接入真实单元时用新增真实身份，不能把旧 DEMO 改名为真实单元并沿用其练习成绩。

## Studio21 A1 Lektion 1 内容包

`studio21/a1/lektion1.json` 依据用户在 2026-10-15 提供的课程概要建立，并于 2026-10-26 扩充练习。内容包包含教材范围、四个小节、18 张知识卡、65 道小节练习和 18 道综合检测题；解释、例句及题目由 DeutschLab 原创编写，没有复制教材原题、对话或听力。页码是概要所给范围，不代表已对照教材原页核验。知识卡、题目和现有 A1 专题分别保持稳定 ID；课程关联不复制 A1 框架原始内容。
